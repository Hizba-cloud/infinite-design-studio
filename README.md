# 🎨 Infinite Studio Ultimate Pro

An interactive, browser-based generative design and branding studio built with **p5.js** and **Tailwind CSS**. Designed for creators and developers to generate aesthetic visual assets, explore procedural mathematics, and export high-resolution graphics or animated loops.

![Infinite Studio Preview](https://img.shields.io/badge/p5.js-Generative_Art-orange?style=for-the-badge)
![License](https://img.shields.io/badge/license-MIT-blue?style=for-the-badge)

---

## ✨ Features

* **60 Unique Procedural Algorithms:** From harmonic Lissajous fields and Fibonacci spiral lattices to quantum flux swirls, 4D hypercube projections, and matrix terminal grids.
* **Interactive Canvas Controls:** Real-time drag-and-drop positioning for text layers and logo/asset overlays.
* **Custom Asset & Typography Injection:** Load custom SVG/image URLs and inject any Google Font instantly.
* **Dynamic Aesthetics:** Quick color palette presets (Cyber Neon, Pastel Dream, Minimal Dark, Solar Flare) with adjustable glow blurs and animation speeds.
* **High-Res & Video Exports:** Download crisp 4K PNG assets (3x scale) or record smooth WebM animations directly in your browser.

---

## 🚀 Getting Started

No complex build steps or installations required! 

1. Clone or download this repository.
2. Open the `index.html` (or your saved HTML file) in any modern web browser.
3. Start creating!
